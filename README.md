# XA GHOST
Offline Bluetooth text messenger for paired Android phones.

Install the same APK on two phones, pair them in Android Bluetooth Settings, tap HOST on one, and CHOOSE PAIRED DEVICE on the other.

No server, internet, root, or account required. Android Bluetooth pairing secures the link, but this test app does not implement application-layer end-to-end encryption. Do not use for confidential conversations.

GitHub Actions builds and publishes a direct APK to Releases.
